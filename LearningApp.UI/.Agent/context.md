# LearningApp Context

LearningApp is a .NET 8 enterprise CRUD sample for learning management. The repository contains two solutions: `LearningApp.Api` for the REST API and `LearningApp.UI` for the hosted Blazor WebAssembly app.

The domain includes users, categories, courses, enrollments, and learning progress. SQL Server scripts are maintained manually under `/Database`; EF Core mappings must stay aligned with those scripts.
